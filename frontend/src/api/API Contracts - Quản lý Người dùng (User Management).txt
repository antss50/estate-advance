2. Xóa tòa nhà
Xóa một hoặc nhiều tòa nhà theo ID.
   * URL: /api/building/{ids}
   * Method: DELETE
   * Path Variable:
   * ids (List<Long>): Danh sách ID các tòa nhà cần xóa, cách nhau bởi dấu phẩy. Ví dụ: 1,2,3
   * Response Thành công (200 OK hoặc 204 No Content):
json
{
        "message": "Xóa thành công",
        "success": true
}

   * URL: /api/building/{id}/staffs
   * Method: GET
   * Path Variable:

VI. Luồng xử lý (Flow)
Luồng 1: Tìm kiếm và hiển thị danh sách
            1. User truy cập /admin/building-list với các tham số tìm kiếm
            2. Controller nhận BuildingSearchRequest và gọi buildingService.findAll()
            3. Service trả về List<BuildingSearchResponse>
            4. View hiển thị danh sách kèm filter
Luồng 2: Thêm/Sửa tòa nhà
            1. User click "Thêm mới" → vào /admin/building-edit (form trống)
            2. User click "Sửa" → vào /admin/building-edit-{id} (form có dữ liệu)
            3. User submit form → gọi API POST /api/building với BuildingDTO
            4. API xử lý và redirect về trang danh sách kèm message
Luồng 3: Gán nhân viên
            1. User click "Giao nhân viên" trên danh sách
            2. Gọi API GET /api/building/{id}/staffs lấy danh sách staff
            3. Hiển thị modal với danh sách và trạng thái check
            4. User chọn staff và submit → gọi API POST /api/building/assignment
            5. Hiển thị thông báo thành công/thất bại
